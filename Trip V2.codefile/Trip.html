이동 루트 지도

번호 마커를 클릭하면 상세 정보와 Google 맵스 링크가 열립니다. 왼쪽 일정 카드를 누르면 지도가 해당 위치로 이동합니다.

본 일정표는 AI 맞춤형 여행 경로 추천 서비스에 의해 생성되었습니다. 실제 이동 시간은 교통 상황에 따라 달라질 수 있습니다.

AI(LLM) 연결 설정

"AI 재요청", "AI 맞춤 여행 경로 생성", "주변 추천 더 보기(AI)" 기능이 이 설정으로 LLM을 호출합니다. 설정하지 않으면 샘플 데이터와 OpenStreetMap 기반 주변 검색으로 동작합니다.

Google AI Studio(aistudio.google.com)에서 무료로 발급할 수 있습니다. 키는 이 브라우저(localStorage)에만 저장됩니다.

직접 호출 방식은 개인 테스트용입니다. 외부에 공개하는 사이트라면 키가 노출되지 않도록 "백엔드 프록시" 방식을 사용하세요.

요청: POST { system, prompt } → 응답: { text }
예제 서버: server/llm-proxy.js (nginx에서 /api/ 경로를 프록시)

Google Maps Platform 키(Places API (New) 사용 설정)를 넣으면 "일정 추가" 추천에 실제 Google 지도 평점·리뷰 수를 사용합니다. 비워 두면 AI 추정 평점 → 내장 샘플 → OpenStreetMap 순으로 대체되며, 각 장소의 구글·네이버·카카오 지도 링크에서 실제 평점을 확인할 수 있습니다.
