# Trip.AI 1차 개발 과정 요약

> 창의공학설계 3조 · AI 기반 여행 경로 추천 HTML 웹사이트

이 문서는 저장소에 있는 Trip.html 코드가 버전별로 어떻게 바뀌었는지 정리한 것.
각 버전의 코드를 서로 비교해서 작성하였음.

## 2. 단계별 작업 내용

### 0단계 — 첫 디자인 (`Trip.backup.html`)

- 흰 배경의 라이트 테마. Tailwind CSS와 Font Awesome으로 3단계 화면 틀 구성
- 장소는 제주 1일차 5곳을 코드에 직접 작성 (각 장소마다 차선책 2곳)
- 교통수단 3종: 자가용 · 대중교통 · 택시
- "AI 재요청" 버튼은 `alert()`만 띄우는 자리표시
- 이동 시간은 "이동 25분" 같은 고정 문구
- 최종 화면: 구글맵 · 네이버 블로그 검색 링크, 인쇄 / PDF 저장

### 1단계 — 초안 (`Trip.html` + `server/llm-proxy.js`)

**디자인**
- 다크 테마와 유리 질감 카드로 전면 변경

**Step 1 · 조건 입력**
- 집 위치, 마지막 날 체크아웃 시간 입력 추가
- 한글 초성 자동완성 (예: `ㄱㄹ` → 강릉, 64개 지역)
- 교통수단 6종: 자가용 · 렌터카 · 대중교통 · 택시 · 공항-비행기 · 여객선
  - 자가용은 단독 선택만 가능, 나머지는 함께 선택 가능

**AI 연동**
- Gemini API 직접 호출 또는 API 키를 숨겨 주는 백엔드 프록시(`llm-proxy.js`) 중 선택
- 사용 가능한 모델 자동 찾기, 연결 테스트
- 응답 지연이나 503 / 429 오류 시 `gemini-2.5-flash`로 자동 전환
- JSON 형식을 지정한 프롬프트로 일정을 받고, 응답을 검증 · 정규화

**Step 2 · 장소 확정 / 보류**
- 장소 카드마다 구글 미니 지도
- 자연어 재요청, 빠른 요청 칩 4개, 되돌리기
- 바뀐 부분만 다시 그려 지도가 깜빡이지 않게 처리

**Step 3 · 최종 루트**
- 집 출발 → 여행 → 집 복귀까지 시간을 분 단위로 누적 계산
- 구간 거리(직선 거리 × 1.28)로 항공 · 여객선 · 렌터카 · 버스 · 택시 요금과 소요 시간 계산
- 구간마다 버스 / 택시를 골라 비교
- Leaflet 지도 + 배경 타일 5종, OSRM으로 실제 도로를 따라가는 경로
- 루트 주변 추천: AI 또는 OpenStreetMap에서 반경 1.5km 안 검색

**함께 만든 파일**
- `Trip.AI_코드_설명서.html`: 초안 코드 구조 설명서
- `server/llm-proxy.js`: Gemini API 프록시 서버 (Node.js 18+, 외부 패키지 없음)

### 2단계 — V2 (`Trip V2.codefile/Trip.html`)

핵심 변화: **AI가 다 짜 주는 방식 → 사용자가 계획 방식을 고르는 방식**

**플래닝 모드 3종**
- AI 자동 추천
- 직접 작성
  - 방식 1: 일차별로 직접 구성
  - 방식 2: 가고 싶은 곳을 한 번에 입력 (`[식당] 우진해장국`처럼 카테고리 지정 가능)
- 하이브리드: 일차마다 위 방식을 섞어 쓰기

**AI 추천 세분화**
- 여행 목적 카테고리 9종 복수 선택 + 카테고리별 세부 취향
- 식당 / 카페 비중, 일정 강도 3단계, 동행 5종, 예산 3단계, 추가 요청 입력

**"일정 추가" 장소 추천 창**
- 추천 데이터를 아래 순서로 찾고, 앞 단계에 결과가 없으면 다음 단계로 넘어감
  1. Google 지도 실제 평점 (Google Places API 키 입력 시)
  2. AI 추정 평점
  3. 내장 제주 장소 DB 69곳
  4. OpenStreetMap
- 리뷰 수가 적은 고평점 장소가 과대평가되지 않도록 베이지안 평균으로 보정
- 정렬 3종 (종합 · 평점 · 거리), 구글 · 네이버 · 카카오 지도 링크, 데이터 출처 배지

**최적 동선 엔진**
- 가까운 장소끼리 묶어 일차 배분
- 하루 안의 순서: 최근접 이웃 방식으로 정한 뒤 2-opt로 개선
- 식당은 식사 시간대에 맞춰 삽입
- 복귀 시간을 넘기면 점수가 낮은 장소부터 제외

**Step 2 보강**
- 일차별 헤더와 "일정 추가" 버튼
- 차선책이 없을 때 평점 기반 대체 장소 찾기
- 작성 중인 일정을 브라우저(localStorage)에 자동 저장

**버그 수정 · 안정화**
- 같은 여행지 안의 먼 구간에도 항공 요금이 붙던 문제 수정 (집 ↔ 여행지, 섬 ↔ 육지 구간에만 적용)
- AI가 "2일차"라고 답해도 Day 2로 인식
- OpenStreetMap 서버 과부하 시 미러 서버 3곳으로 재시도
- 초안 CSS의 오타(`ㄴrgba`)로 테두리 스타일이 적용되지 않던 문제 수정
- 모바일에서 화면이 가로로 넘치던 문제 수정

### 3단계 — V3 (`Trip.AI.V3 코드파일/TripAI-v3.html`)

핵심 변화: **실제 여행 당일의 디테일과 예약 연결**

**첫날 숙소 체크인**
- 체크인 시간 + "체크인 후 관광 / 짐 맡기고 먼저 관광" 선택
- "집 → 숙소 → 체크인 → 관광" 흐름 미리보기
- 타임라인, 지도, 동선 계산, AI 프롬프트에 모두 반영

**구간별 예매 · 예약 바로가기**
- 항공권: 국내 공항 14곳과 실제 운항 노선표로 공항 쌍 선택, 네이버 항공권에 노선 · 날짜 자동 입력, 해외 공항 51곳 지원
- 터미널 버스: 고속 · 시외버스 예매 링크, 100km 이상 구간은 KTX / SRT 링크 추가
- 렌터카: 제주 / 국내 / 일본 / 해외별 예약 링크

**시내버스 노선 번호**
- Google 대중교통 길찾기(Routes API) → AI 추정 → 카카오맵 링크 순서로 조회
- 화면을 먼저 보여 주고 번호는 뒤에서 조회, 한 번 찾은 구간은 다시 조회하지 않음

**AI 결과 보정**
- AI가 출발지 쪽 교통 거점(예: 김포공항)을 일정에 넣으면 자동 제외
  - 그대로 두면 제주 ↔ 김포 580km를 오가는 루트가 생기기 때문
- 집으로 돌아가는 날은 렌터카 "반납"으로 표시
- 복귀 시간을 넘길 때 뺄 장소를 "손실이 가장 적은 것" 기준으로 선택

**UX 개선**
- 확정된 카드에 LED처럼 숨쉬는 효과 (모든 카드가 같은 박자, "움직임 줄이기" 설정 시 정지)
- "처음으로 되돌아가기" 버튼 (최종 화면 위 · 아래, 입력한 조건은 유지)
- 한글이 단어 단위로 줄바꿈되도록 처리
- 화면 하단 고정 버튼 위로 미니 지도 링크가 겹치던 문제 수정

## 4. 사용 기술 · 외부 서비스

| 구분 | 내용 |
|---|---|
| 화면 | HTML 단일 파일, Tailwind CSS (CDN), Font Awesome 6.4, Pretendard 폰트 |
| 지도 | Leaflet 1.9.4, Google / OpenStreetMap 타일, Google Maps Embed |
| 위치 · 경로 | OSRM (도로 경로), Nominatim (주소 → 좌표), Overpass API (주변 장소) |
| AI | Google Gemini API (직접 호출 또는 백엔드 프록시) |
| 평점 · 대중교통 | Google Places API (V2~), Google Routes API (V3) |
| 백엔드 | Node.js 18+ `llm-proxy.js`, Nginx 리버스 프록시 |
| 저장 | 브라우저 localStorage (AI 설정, 지도 평점 키, 작성 중인 일정) |

## 5. 실행 방법

1. HTML 파일을 브라우저로 열면 바로 실행됩니다. AI를 연결하지 않아도 내장 제주 샘플 데이터로 전체 흐름을 체험할 수 있음. 
2. AI를 쓰려면 화면 오른쪽 위 **AI 설정**에서 둘 중 하나를 선택함. 
   - **Gemini API 직접 호출:** API 키 입력
   - **백엔드 프록시:** 아래처럼 프록시 서버를 실행한 뒤 URL에 `/api/llm` 입력

```powershell
# PowerShell
$env:GEMINI_API_KEY="발급받은_키"; node server/llm-proxy.js
```

```nginx
# conf/nginx.conf 의 server { ... } 블록 안에 추가
location /api/ {
  proxy_pass http://127.0.0.1:8787;
  proxy_read_timeout 120s;
}
```

3. (선택, V2~) **AI 설정**에 Google Places API 키를 넣으면 실제 Google 지도 평점으로 장소를 추천하고, V3에서는 시내버스 번호 조회에도 사용한다.
